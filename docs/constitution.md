# Constitución de Mercadata

## Principios Fundamentales

1. **Precios Reales y Transparentes**:
   - Todo precio presentado al usuario debe ser el precio final de venta al consumidor, incluyendo el IVA donde aplique (16% en Venezuela) o reflejando exención (0%).
2. **Comparación Equitativa**:
   - Para que la comparación sea justa, todos los productos deben convertirse a una moneda común (USD o VES) utilizando la tasa oficial del Banco Central de Venezuela (BCV).
3. **Exactitud en Búsqueda y Presentaciones**:
   - Si el usuario especifica una presentación o tamaño (ej. `1lt`, `2l`, `500g`), la plataforma debe filtrar con precisión estricta para no comparar presentaciones desiguales.
4. **Resiliencia y Rendimiento**:
   - Si un supermercado se encuentra caído o con latencia, la plataforma debe responder con los datos de las tiendas disponibles sin bloquear la búsqueda general.
